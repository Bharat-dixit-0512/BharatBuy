# 🛒 BharatBuy – Full Stack E-Commerce Platform

BharatBuy is a full-stack e-commerce web application built to simulate a real-world online shopping experience.  
It supports user authentication, product browsing, cart management, secure payments, and an admin dashboard for product and order management.

This project is designed with **scalability, security, and clean architecture** in mind and is suitable for showcasing full-stack development skills on a resume.

---

## 🚀 Features

### 👤 User Features
- User registration and login (JWT authentication)
- Secure password hashing
- Browse products by category
- Product search and filtering
- Add/remove products from cart
- Update product quantity in cart
- Checkout with secure payment gateway
- View order history
- User profile management

### 🛠 Admin Features
- Admin authentication
- Add, update, and delete products
- Manage product inventory
- View all orders
- Update order status (Pending, Shipped, Delivered)
- User management

### 💳 Payment
- Secure payment integration using **Stripe**
- Order creation after successful payment
